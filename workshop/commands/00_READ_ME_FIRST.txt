=====================================================================
  ILP WORKSHOP · HOW TO USE THESE COMMAND FILES
=====================================================================

1. In VS Code: File > Open Folder > Desktop > workshop
2. Open this file (click it on the left side). It opens at the TOP.
3. Open the terminal at the BOTTOM:   Ctrl + `   (the key above Tab)
4. Make the terminal "Git Bash":
      Click the  v  next to the + in the terminal > Git Bash
      (Linux commands work in Git Bash on Windows.)
5. Do the steps one by one: read the command, type it in the terminal,
   press Enter, and compare with "You should see".

RULES
  - Type the commands yourself. If you are slow, copy-paste is OK.
  - Do not skip steps. Each step needs the one before it.
  - If you see something different from "You should see", show your
    HELP tent and wait for a trainer.
